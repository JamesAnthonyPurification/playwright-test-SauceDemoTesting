Page Object Model (pages/)

Every SauceDemo screen has its own JavaScript class that receives the Playwright page object in its constructor, encapsulates element locators, and exposes reusable methods.

  • BasePage.js — Shared visit() and URL helper methods.
  • LoginPage.js — Username, password, login button, error assertions, and login().
  • InventoryPage.js — Sorting (az, za, lohi, hilo), add/remove by name, cart badge count.
  • InventoryItemPage.js — Product detail info, add/remove from detail view, back button.
  • CartPage.js — Cart item listing, remove single or all items, continue shopping, checkout.
  • CheckoutPage.js — Step 1 form validation, Step 2 subtotal/tax/total calculations, finish order.
  • MenuComponent.js — Reusable sidebar component: open, close, All Items, Reset App State, Logout.

Test Organization (tests/ & fixtures/)

Test files focus strictly on scenarios and assertions while reusing page class methods and centralized JSON data.

  • tests/recorded.spec.js — Preserved Playwright Codegen tests (TC01 Login & TC02 Add Backpack).
  • tests/login.spec.js — 7 authentication & validation tests using all 4 lifecycle hooks.
  • tests/inventory.spec.js — 6 sorting, cart badge, and add/remove tests.
  • tests/inventoryItem.spec.js — 4 product detail view tests.
  • tests/cart.spec.js — 5 shopping cart management & navigation tests.
  • tests/checkout.spec.js — 6 end-to-end checkout, pricing math, and form validation tests.
  • tests/menu.spec.js — 4 sidebar menu, state reset, and logout tests.
  • fixtures/testData.json — Users, products, checkout inputs, and expected error strings.

test.beforeAll() & test.afterAll()

Run once per test file (per worker).

Used in tests/login.spec.js for shared setup that does not belong to a single browser page: beforeAll() creates a Playwright request API context to verify SauceDemo responds with HTTP 200, and afterAll() disposes that context after all login tests complete.

test.beforeEach() & test.afterEach()

Run before and after every individual test.

beforeEach() initializes fresh Page Objects and navigates to the required starting screen (for example, logging in and adding items before cart/checkout tests). afterEach() in tests/login.spec.js attaches the failing URL to the report whenever a test fails. Playwright automatically isolates and closes each test's browser context.
